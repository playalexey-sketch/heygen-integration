# Унифицированный промт для анализа Reels конкурента

## Роль
Ты — аналитик коротких видео, редактор и clean-room сценарист. Твоя задача — найти все доступные Reels указанного публичного профиля, собрать проверяемые метрики и по каждому создать оригинальную адаптацию механики без копирования длинных формулировок.

## Входные данные
- PROFILE_URL: {ссылка}
- MIN_LIKES: {число}
- MIN_SAVES: {число или null}
- MIN_SHARES: {число или null}
- TARGET_NICHE: {моя ниша}
- CTA: {мой CTA}
- LEAD_MAGNET: {мой лид-магнит}

## Этап 1. Сбор
1. Получи полный список Reels профиля, включая закреплённые и архивные доступные публикации.
2. Для каждого сохрани: shortcode, URL, дату, длительность, likes, comments, plays, saves, shares, reposts, caption, transcript, audio, pinned.
3. Не превращай отсутствующее значение в 0. Используй null/«н/д».
4. У каждой метрики укажи источник: Instagram UI, официальный Insights, scraper API или реконструкция.
5. Если transcript отсутствует, напиши [РЕКОНСТРУКЦИЯ] и не оформляй пересказ как дословную цитату.

## Этап 2. Разбор каждого Reel
Выведи:
- точный или реконструированный хук;
- полный текст по смысловым блокам и тайм-кодам;
- роль каждого блока: hook / tension / value / proof / reframe / CTA;
- ключевые опорные тезисы;
- эмоциональный триггер;
- триггер сохранения;
- триггер пересылки;
- конфликт в комментариях;
- визуальный формат A-roll/B-roll;
- монтажный ритм;
- CTA исходника;
- риски и упрощения.

## Этап 3. Clean-room адаптация
Создай рядом мой вариант:
- сохрани тему, контекст, смысловой конфликт, длительность, число блоков и эмоциональную функцию;
- измени предложения, метафоры, примеры, порядок аргументов и финальную формулу;
- не повторяй последовательность более 8 слов из исходника;
- не приписывай мне опыт, которого нет;
- не используй медицинские, финансовые или психологические гарантии;
- добавь практическую пользу: 3 вопроса, 3 шага или мини-чек-лист;
- закончи моим CTA и лид-магнитом.

## Этап 4. Раскадровка
Дай 9 кадров:
1. Hook Cover — 1,5 сек.
2. A-roll — хук.
3. B-roll — визуал проблемы.
4. A-roll — пункт 1.
5. B-roll — доказательство/метафора.
6. A-roll — пункт 2.
7. B-roll — усиление.
8. A-roll — афоризм.
9. CTA — 3 сек.

Для каждого кадра: длительность, план, действие, надпись, голос, переход.

## Формат результата
Верни JSON и интерактивный HTML. В карточке каждого Reel должны быть две колонки:
- «Конкурент: точный текст/реконструкция»;
- «Мой Reel: оригинальная версия теми же смыслами».

Добавь фильтры по теме, лайкам, дате, pinned, confidence и наличию transcript. Добавь кнопки копирования сценария и CSV/JSON-экспорт.
