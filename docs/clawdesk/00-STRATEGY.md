# 00 · Стратегия: ClawDesk

## 1. Что на самом деле показали

Разберём новость по фактам, отделив анонс от механики.

**Факты, которые подтверждаются источниками:**

- Grok Bot запущен 11 августа 2026 в early beta, силами SpaceXAI (бывш. xAI) совместно с Cursor.
- Доступ гейтится тремя тарифами: SuperGrok Heavy ($300/мес), Cursor Ultra ($200/мес),
  Cursor Teams Premium ($120/место). Отдельной подписки нет, enterprise — по листу ожидания.
- Платформы: macOS (ARM/Intel), Windows x64, Linux .deb, iOS. Android — «скоро».
- Каждому пользователю выдаётся облачная машина; в собственной документации указано, что
  **машина одна на аккаунт и делится между ботами**, и что разделение ботов **не является
  границей безопасности**. Изоляция — per user, не per bot.
- Боты подписываются в приложения через UI, а не через API; хранят контекст между задачами;
  переписываются между собой; работают в групповых чатах; возвращаются за аппрувом.
- Обозреватели прямым текстом описывают продукт как «user-friendly OpenClaw».

**Что это значит на самом деле:**

| Заявленное | Что под капотом | Комментарий |
|---|---|---|
| «У каждого бота свой компьютер» | Одна VM на аккаунт, боты делят её | Маркетинговое упрощение. Настоящий per-bot sandbox — это то, чем можно выиграть |
| «Логинится сам в почту и CRM» | Персистентный браузерный профиль + куки + человек логинится один раз руками | Автологин по паролям агентом = блокировки аккаунтов. Все делают ручной вход |
| «Покажи один раз — дальше сам» | Демонстрация → извлечение процедуры → сохранённый markdown-скрипт | Это ровно `SKILL.md` из OpenClaw, только записанный по трассе действий |
| «Боты переписываются между собой» | Agent-to-agent сообщения + общие треды | В OpenClaw есть `tools.agentToAgent` и `sessions_spawn`, выключено по умолчанию |
| «Разница между 90% и 100%» | Очередь аппрувов + ретраи + ledger задач | Это операционная дисциплина, а не свойство модели |
| «ИИ-коллега за $120» | $120/место в самом дорогом командном тарифе | Ниже $120 нет входа вообще |

**Вывод:** технологического рва нет. Есть ров дистрибуции (Cursor уже стоит в репозиториях
и привычках разработчиков) и ров капитала (постоянно живущие VM + фронтир-инференс дорогие).
Оба обходятся: дистрибуцию заменяет self-hosted и открытость, капитал — тем, что VM живёт
у клиента и модель клиент приносит свою.

## 2. Позиционирование ClawDesk

> **ClawDesk — команда ИИ-сотрудников в мессенджере, которая живёт на вашем железе,
> работает вашими ключами и не просит $120 за место.**

Три отличия, которые формулируем в каждом материале:

1. **Настоящая изоляция.** Один бот = один контейнер = один браузерный профиль = один набор
   секретов. Не «не считайте это границей безопасности», а именно граница безопасности,
   с политикой, аудитом и раздельным отзывом доступов.
2. **Свои ключи, своя площадка.** Anthropic / OpenAI / OpenRouter / локальная Ollama / vLLM —
   на выбор, с failover. Развёртывание: ноутбук, свой VPS, VPC клиента. Данные не покидают периметр.
3. **Цена, объяснимая в строке.** Подписка за оболочку, инференс по факту у провайдера.
   $29/мес индивидуально против $120–$300.

Против кого играем и чем:

| Игрок | Их сила | Наш ответ |
|---|---|---|
| Grok Bot / Cursor | Дистрибуция, единая VM, полировка | Self-hosted, per-bot изоляция, цена, открытый код |
| ChatGPT Agent / Claude Cowork | Бренд, качество модели | Мультипровайдерность, работа в контуре, никакого вендор-лока |
| Голый OpenClaw | Бесплатен, мощен | Мы и есть OpenClaw + продуктовый слой: не нужно быть девопсом |
| n8n / Make + LLM-нода | Дёшево, привычно | Нет UI-автоматизации в залогиненных приложениях, нет памяти, нет диалога |

Кому продаём в первую очередь: команды 5–50 человек, у которых есть повторяющаяся
работа в SaaS-интерфейсах без нормального API — агентства, ecom-операции, рекрутинг,
финансовый бэкофис, саппорт второй линии.

## 3. Продуктовая метафора

Мессенджер, где список чатов — это штат:

```
┌─ ClawDesk ──────────────────────────────────────────────┐
│ ЧАТЫ                    │  #финансы-квартал             │
│ ─────────────────────── │  ──────────────────────────── │
│ 🟢 Алиса · финансы   2  │  Вы: собери расходы за Q2     │
│ 🟡 Борис · саппорт      │       из банка и Notion       │
│ 🔵 Вера · рекрутинг     │                               │
│ ⚪ Гоша · ресёрч        │  Алиса ▸ план на 5 шагов      │
│ ─────────────────────── │    └ тред: 4/5 ✓ 1 в работе   │
│ # финансы-квартал    ●  │                               │
│ # запуск-лендинга       │  Алиса ▸ Нужен аппрув:        │
│ ─────────────────────── │    платёж 42 300 ₽ поставщику │
│ ⏸ АППРУВЫ            3  │    [Показать] [Ок] [Отклонить]│
│ 📋 ЗАДАЧИ            12 │                               │
└─────────────────────────────────────────────────────────┘
```

Ключевые UX-принципы:

- **Ничего похожего на дашборд.** Отчёт — это сообщение в треде, а не карточка в канбане.
- **Тред = задача.** У треда есть статус, стоимость, длительность, артефакты, лог действий.
- **Аппрув — это сообщение с кнопками**, а не отдельный раздел, куда надо ходить.
  Раздел «Аппрувы» существует только как сводка невыполненного.
- **Присутствие честное.** 🟢 работает, 🟡 ждёт тебя, ⚪ спит. Статус берётся из реального
  состояния сессии, а не рисуется.
- **Показать работу.** У любого шага есть кнопка «показать» — скриншот/запись экрана
  того, что бот делал в браузере. Это главный инструмент доверия.

## 4. Бизнес-модель

| План | Цена | Что входит |
|---|---|---|
| Solo | $0 (self-host) | 1 бот, свои ключи, локальный gateway, комьюнити-поддержка |
| Pro | $29/мес | До 5 ботов, обучение задач, аппрувы, аудит-лог 90 дней, автообновления |
| Team | $19/место/мес | Общие боты, групповые треды, RBAC, SSO (OIDC), аудит 1 год |
| Managed VPC | от $2 000/мес | Развёртывание в контуре клиента, SLA, обучение, кастомные скиллы |

Юнит-экономика Pro (в месяц, на активного пользователя):

- Инференс — платит клиент своим ключом (наша себестоимость 0).
- Sandbox-контейнеры — 2–4 ГБ RAM в простое схлопываются в ноль (idle-freeze), $3–6.
- Хранение артефактов/скриншотов — $1–2.
- Итого себестоимость ≈ $5–8 при цене $29 → валовая маржа ~75%.

Против $120: мы можем дать цену в 4 раза ниже именно потому, что не перепродаём инференс
и замораживаем простаивающие машины. Это надо писать на лендинге явно.

## 5. Дорожная карта

**M0 · Каркас (2 недели).** Gateway + WebChat-форк как мессенджер, реестр ботов,
per-bot docker-sandbox, один канал (Telegram) как мобильный вход.

**M1 · Мессенджер-first MVP (4 недели).** Треды-задачи, очередь аппрувов, ledger задач,
браузер с персистентным профилем, ручной логин, аудит действий со скриншотами.

**M2 · Обучение задач (4 недели).** Режим «покажи один раз»: запись демонстрации →
генерация `SKILL.md` через Skill Workshop → тестовый прогон → расписание.

**M3 · Команда ботов (3 недели).** Групповые треды, agent-to-agent с политикой,
диспетчер задач, роли и профили инструментов.

**M4 · Enterprise (4 недели).** OIDC/SAML, RBAC, политики DLP, экспорт аудита,
Helm-чарт для VPC, отчёты по стоимости.

**M5 · Экосистема.** Маркетплейс ботов и скиллов поверх ClawHub, шаблоны отделов
(«Финансы», «Саппорт», «Рекрутинг») в один клик.

## 6. Риски и как их снимаем

| Риск | Вероятность | Митигация |
|---|---|---|
| Блокировка аккаунтов за автоматизацию UI | Высокая | Только ручной первичный логин, человеческий темп кликов, per-bot профиль, детект капчи → эскалация человеку |
| Prompt injection со страницы/письма | Высокая | Недоверенный контент только в ограниченном профиле инструментов; никаких секретов в контексте; аппрув на любое необратимое действие |
| Утечка секретов в лог модели | Средняя | Секреты только через SecretRef, подстановка на уровне рантайма, редакция в транскриптах |
| Взрыв стоимости токенов | Средняя | Бюджет на бота и на задачу, hard-stop, дешёвая модель по умолчанию + эскалация на дорогую |
| «90% готово» — молчаливые провалы | Высокая | Ledger задач + обязательный self-check шаг + правило «не отвечай «готово» без артефакта» |
| Юридические ограничения на автоматизацию | Средняя | Явный чек-лист ToS по каждому подключаемому сервису, приоритет API там, где он есть |

## 7. Как измеряем успех

- **TTFV** (time to first value): от установки до первой выполненной ботом задачи — цель < 20 мин.
- **Доля задач, доведённых до 100%** без вмешательства человека — цель > 70% на обученных рутинах.
- **Аппрувов на задачу** — цель < 1.5 (иначе бот не экономит время).
- **Стоимость задачи** в токенах — медиана и p95, показываем пользователю в треде.
- **Retention недельный** по активным ботам, а не по пользователям.
