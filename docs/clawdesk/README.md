# ClawDesk — «Grok Bot» на базе OpenClaw

Рабочее название продукта: **ClawDesk** (внутренний кодовый: `clawdesk`).

Мессенджер, в котором ты — единственный человек. Все остальные контакты — боты-сотрудники
с собственным облачным компьютером, памятью, доступами и правом действовать самостоятельно
до момента, когда нужна твоя подпись.

Это не форк OpenClaw. Это **продуктовый слой поверх OpenClaw Gateway**: OpenClaw даёт
рантайм агентов, каналы, сессии, инструменты, sandbox и sub-агентов; ClawDesk даёт
мессенджер-first UX, реестр ботов, изоляцию «один бот = один компьютер», обучение задач
с одного показа, очередь аппрувов, аудит и биллинг.

## Быстрый TL;DR

- **Grok Bot ≈ user-friendly OpenClaw + мессенджер-метафора + управляемая VM на пользователя.**
  Инсталляторы на `downloads.cursor.com`, разработчик в App Store — Anysphere: это продукт Cursor
  в обёртке Grok. Гейт по цене $120–$300/мес — это гейт по стоимости инференса и по стоимости
  постоянно живущей VM, а не по технологии.
- **Технологического рва нет.** Всё, на чём стоит Grok Bot, в OpenClaw уже есть:
  gateway + multi-agent routing + sub-агенты + agent-to-agent + skills + cron/hooks +
  браузер с постоянным профилем + docker-sandbox + ledger задач.
- **Ров — в UX и в операционке**: мессенджер, который не выглядит как дашборд; «покажи один раз»
  вместо промпт-инжиниринга; очередь аппрувов, которой можно доверять; аудит, который переживёт
  проверку безопасника; цена, где обвязка не съедает маржу.
- **Наша ставка:** self-hosted / VPC-first, оплата за результат, вход от $29/мес на своих ключах.
