### Как сгенерировать B-roll/аватар-дубли (из этого репозитория)

**Вариант A — бесплатно, локально, нужен GPU (LTX-2):**
```bash
python ltx2_agent.py --photo expert.jpg --audio broll_voice.wav \
  --aspect portrait --duration 10 --out broll_1.mp4
```

**Вариант B — платно, из облака, без своей видеокарты (HeyGen):**
```bash
python photo_video_agent.py --photo expert.jpg --audio broll_voice.mp3 \
  --duration 10 --out broll_1.mp4
```
