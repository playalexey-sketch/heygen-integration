# 📋 SPRINTS.md — Мастер-бэклог конвейера «Личный бренд под ключ»

Формат каждого спринта одинаковый, чтобы любую карточку можно было прямо
перенести в Jira/Trello/Linear как эпик с чек-листом задач.

Условные обозначения:
- **Вход** — что обязательно должно быть на руках до старта спринта.
- **AI-инструмент** — какой инструмент этого репозитория используется и как.
- **Продукт спринта (DoD)** — конкретный артефакт(ы), который получает клиент;
  спринт закрыт только когда все пункты DoD выполнены.

## Спринт 1 — «Досье эксперта»
**Домен:** autoexpert-profile.com · **Длительность:** 1–2 дня · **Цена:** от 15 000 ₽

| | |
|---|---|
| **Цель** | Собрать полное досье личного бренда, чтобы любой копирайтер/AI мог писать контент за эксперта без дополнительных вопросов |
| **Вход** | Ссылки на соцсети клиента, 30-минутный созвон (запись/расшифровка) |
| **Роли** | Интервьюер, аналитик-копирайтер |

**Задачи:**
1. Провести структурированное интервью (30 мин) по чек-листу: биография, ценности, кейсы, боли ЦА, стиль речи, лексика-паразиты, табу-темы.
2. Собрать и рассортировать цифровые активы: фото, видео, отзывы, скрины кейсов, ссылки.
3. Прогнать расшифровку интервью через **Hermes-чат** (`hermes/`, модель `hermes3:8b`) с промптом «извлеки Tone of Voice, 5 сигнатурных фраз, 3 главные боли ЦА, список кейсов с цифрами».
4. Собрать PDF на 10–15 страниц по шаблону `templates/01_dosye_eksperta.md`.
5. Собрать «Таблицу ассетов» (Google Sheets/Excel) — ссылки на всё, что есть у клиента.

**AI-инструмент:** Hermes-чат — структурирование расшифровки интервью, извлечение Tone of Voice.

**Продукт спринта (DoD):**
- [ ] PDF «Досье эксперта», 10–15 стр., по шаблону `01_dosye_eksperta.md`
- [ ] Таблица ассетов (ссылки на фото/видео/кейсы/отзывы)
- [ ] Профиль Tone of Voice (5 фраз-маркеров + список табу)
- [ ] Согласовано с клиентом (1 раунд правок)

**Что дальше:** Досье — обязательный вход для спринтов 3, 6, 7.
