# 🚀 AI-конвейер «Личный бренд под ключ» — 10 спринтов, 10 продуктов

Этот пакет превращает список продуктовых лендингов в **работающий production-план**:
каждый спринт = отдельная команда/отдельный трек работы = один **законченный,
самостоятельно продаваемый продукт** на выходе. Продукты физически связаны:
выход спринта N — обязательный вход спринта N+1 (см. колонку «Вход» в
[`SPRINTS.md`](./SPRINTS.md)).

Технически конвейер опирается на инструменты, уже собранные в этом репозитории:

| Инструмент репозитория | Где используется в конвейере |
|---|---|
| 🧠 `hermes/` — локальный чат Hermes (Ollama, бесплатно, без API-ключа) | Спринты 1–6, 10: интервью, анализ, тексты, сценарии, диалоги, SEO |
| 🎬 `heygen_client.py` / `heygen_tools.py` / Video Agent | Спринты 7, 9: демо-ролики по сценарию, референс для монтажа |
| 📸 `photo_video_agent.py` (HeyGen Photo→Video) | Спринты 8, 9: фото эксперта → говорящий аватар для визуального пакета и B-roll |
| 🎞️ `ltx2_agent.py` (открытая LTX-2, без платного API) | Спринт 9: альтернативная генерация B-roll/аватар-дублей без бюджета на HeyGen |
| `webui/` (веб-форма генерации видео) | Спринты 7–9: без кода, из браузера |

## Состав пакета

| Файл/папка | Назначение |
|---|---|
| [`SPRINTS.md`](./SPRINTS.md) | Мастер-бэклог: цель, вход/выход, задачи, роли, AI-workflow, DoD, цена — по каждому из 10 спринтов |
| `templates/` | 10 шаблонов **готового продукта** — то, что реально отдаётся клиенту после спринта |
| `scripts/new_client.py` | Скрипт-скаффолдер: создаёт папку клиента со всеми 10 шаблонами и файлом статуса конвейера |
| `site/` | 10 статических лендингов (по одному на продукт) + общая витрина `index.html` |

## Быстрый старт

```bash
# 1. Завести нового клиента (создаст sprints/deliverables/<client>/ с шаблонами 01..10)
python sprints/scripts/new_client.py "Имя_Клиента"

# 2. (если меняли данные в site/data.py) пересобрать лендинги
python sprints/site/generate_site.py

# 3. Открыть витрину лендингов локально (сервер из папки sprints/,
#    чтобы работали ссылки на SPRINTS.md и templates/)
python -m http.server 8080 --directory sprints
# открыть http://localhost:8080/site/index.html
```

## Как AI реально помогает на каждом спринте

1. Заполняешь входные данные клиента (бриф) в карточку спринта.
2. Открываешь Hermes-чат (`hermes/`, `http://localhost:8002`) и используешь
   готовый промпт из `templates/<N>_*.md` → раздел **«Промпт для Hermes»**.
3. Для видео-спринтов (7 и 9) — `webui/` или `photo_video_agent.py` собирают
   демо-ролик по сценарию/аватару.
4. Результат вставляется в шаблон, документ проверяется по чек-листу DoD
   из `SPRINTS.md`, оформляется в PDF/Notion и уходит клиенту — это и есть
   законченный продукт спринта.
