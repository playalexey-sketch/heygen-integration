# Карусель «Ты следующий?»

8 слайдов для Instagram, формат **1080×1350** (4:5).

## Файлы
- `out/slide_1.png` … `out/slide_8.png` — готовые слайды по порядку
- `out/preview_all.jpg` — контактный лист (все 8 в одном изображении)
- `bg/bg1.png`, `bg/bg2.png` — фоны (чередуются: 1,3,5,7 — лучи; 2,4,6,8 — родовое древо)
- `fonts/` — Roboto (Black / Bold / Medium / Regular)
- `make_carousel.py` — генератор

## Как перегенерировать / править текст
```bash
pip install pillow
python3 carousel/make_carousel.py
```
Тексты лежат в списке `SLIDES` внизу скрипта. Каждый блок — пара `(стиль, текст)`:

| стиль | назначение |
|---|---|
| `h1` | крупный заголовок капсом |
| `h2` | заголовок предложением |
| `gold` | золотой акцент (ключевая мысль) |
| `bodyw` | белый подводящий текст |
| `body` | основной серый текст |
| `cta` | заголовок призыва |
| `zero` | огромная цифра 0 |
| `rule` | золотая разделительная черта |

Перенос строки — `\n`. Размеры шрифта подгоняются автоматически, если текст не влезает в безопасную зону.
