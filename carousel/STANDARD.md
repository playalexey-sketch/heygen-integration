# МАСТЕР-ПРОМТ / СТАНДАРТ КАРУСЕЛЕЙ (v2)

> Этот файл — источник правды. Любая новая карусель делается ТОЛЬКО по этим правилам.
> Технически стандарт зашит в `engine.py`; контент лежит отдельно в `slides_*.py`.

---

## 1. Технические параметры

| Параметр | Значение |
|---|---|
| Размер | **1080 × 1350 px** (4:5, вертикаль под Instagram) |
| Формат | PNG, качество 95 |
| Поля | 96 px по бокам |
| Безопасная зона | 150 px сверху, 130 px снизу |
| Шрифт | Roboto (Black / Bold / Medium / Regular), кириллица |
| Выравнивание | по центру, текст вертикально центрирован |

## 2. Палитра

| Роль | Цвет |
|---|---|
| Фон | чёрный / глубокий тёмный + затемняющая вуаль |
| Заголовки | белый тёплый `#F5F2EC` |
| Ключевая мысль (акцент) | золото `#F0CD8C` |
| Основной текст | серый `#B0ACA5` |
| Линии, номер, микро-CTA | золото `#D6AF6A` |

## 3. Обязательные элементы оформления

1. **Вверху слева — только номер слайда** (`01`, `02`, …) + короткая золотая линия.
   **Никаких тегов, названий блоков и подписей.**
2. **Внизу — ПУСТО.** Никаких «свайпай», «листай дальше», нумерации внизу и т.п.
3. **На последнем слайде** под основным CTA — золотая разделительная линия и
   **дополнительный микро-призыв, выбранный СЛУЧАЙНО** из пула:
   - «Подпишись, чтобы не потерять.»
   - «Сохрани этот пост, чтобы вернуться.»
   - «Отправь близкому человеку, которому это откликнется.»
   - «Поставь лайк, если узнал свой Род.»
4. Фоны чередуются через слайд, чтобы карусель «дышала», но остаётся один визуальный мир.
5. Размер шрифта авто-подгоняется вниз, пока текст не влезет в безопасную зону —
   слайд никогда не обрезается.

## 4. Драматургия карусели (структура смыслов)

| № | Блок | Задача |
|---|---|---|
| 1 | **Хук** | Остановить скролл. Короткий вопрос-удар + обещание темы |
| 2 | **Узнавание проблемы** | Перечислить симптомы так, чтобы читатель узнал себя |
| 3 | **Раскачивание** | Проекция в будущее: что будет, если ничего не менять |
| 4 | **Цена бездействия** | Назвать настоящую цену. Самый эмоциональный слайд |
| 5 | **Поворот** | Дать надежду и субъектность: «этим человеком можешь стать ты» |
| 6 | **Что внутри** | Назвать продукт и его глубину, а не только форму |
| 7 | **Формат** | Снять страх: как именно проходит, сколько занимает |
| 8 | **CTA** | Одно простое действие + дефицит + случайный микро-призыв |

## 5. Правила текста

- Короткие строки, много воздуха, ручные переносы `\n` — читаем с телефона.
- Один слайд = одна мысль. Не больше 1–2 золотых акцентов на слайд.
- Обращение на «ты», без канцелярита и без обещаний гарантированного результата.
- Целевое действие — всегда одно и то же и предельно простое (например «напиши 0»).

## 6. Стили блоков (для `slides_*.py`)

| Стиль | Применение |
|---|---|
| `h1` | крупный заголовок капсом (хук, «Одна встреча») |
| `h2` | заголовок предложением |
| `gold` | золотой акцент — ключевая мысль слайда |
| `bodyw` | белый подводящий текст |
| `body` | основной серый текст |
| `small` | мелкая сноска |
| `cta` | заголовок призыва на последнем слайде |
| `zero` | огромная цифра-триггер |
| `action` | микро-призыв (ставится движком автоматически) |
| `rule` | золотая разделительная черта |

## 7. Как сделать новую карусель

```bash
cp carousel/slides_ty_sleduyushiy.py carousel/slides_моя_тема.py
# отредактировать список SLIDES: пары (стиль, текст)
python3 carousel/slides_моя_тема.py
```

Движок сам: отрисует номера, уберёт нижние подписи, подгонит кегль,
добавит случайный микро-призыв на последний слайд и соберёт `preview_all.jpg`.

Зафиксировать конкретный микро-призыв (если нужен не случайный):
```python
build(SLIDES, OUT, action_cta="Сохрани этот пост, чтобы вернуться.")
```
