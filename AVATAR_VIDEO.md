# Видео цифрового аватара: твоё фото + твой голос

Скрипт: `make_avatar_video.py`

---

## Шаг 1. Ключ HeyGen

Создай в корне проекта файл `.env`:

```
HEYGEN_API_KEY=hg_твой_ключ
```

Ключ: https://app.heygen.com/settings/api
Файл `.env` уже в `.gitignore` — в репозиторий он не попадёт.

## Шаг 2. Установка

```bash
pip install -r requirements.txt
```

## Шаг 3. Материалы

**Фото аватара**
- портрет анфас, лицо занимает заметную часть кадра
- глаза открыты, взгляд в камеру, нейтральное или лёгкое выражение
- ровный свет, без жёстких теней на лице
- без солнцезащитных очков, масок, кепок с тенью
- подбородок и лоб не обрезаны
- JPG/PNG, от 1000 px по ширине

**Образец голоса** (для клонирования)
- чистая запись 30–120 секунд
- только один говорящий, без музыки и фонового шума
- обычный темп и интонация, как в ролике
- MP3 или WAV

## Шаг 4. Запуск

### Вариант А — аватар говорит текст ТВОИМ голосом (клонирование)

```bash
python make_avatar_video.py \
  --photo my_photo.jpg \
  --voice-sample my_voice.mp3 \
  --script "Текст, который произнесёт аватар." \
  --aspect-ratio 9:16 \
  --out avatar_video.mp4
```

После первого запуска скрипт напечатает **ID клонированного голоса**.
Сохрани его — дальше можно не клонировать заново:

```bash
python make_avatar_video.py --photo my_photo.jpg \
  --voice-id ВСТАВЬ_ID --script "Новый текст" --out video2.mp4
```

### Вариант Б — готовая озвучка (аватар липсинкает аудио)

```bash
python make_avatar_video.py \
  --photo my_photo.jpg \
  --audio speech.mp3 \
  --aspect-ratio 9:16 \
  --out avatar_video.mp4
```

## Параметры

| Флаг | Назначение |
|---|---|
| `--photo` | портретное фото (обязательно) |
| `--voice-sample` | запись голоса для клонирования |
| `--audio` | готовая озвучка вместо синтеза |
| `--script` | текст для произнесения |
| `--voice-id` | ID голоса (клонированного ранее или из библиотеки) |
| `--aspect-ratio` | `9:16` Reels/Stories, `16:9` YouTube, `1:1` лента |
| `--resolution` | `1080p` / `720p` |
| `--background` | hex-цвет (`#0B0B0F`) или URL картинки |
| `--out` | путь сохранения mp4 |

## Сколько ждать

Клонирование голоса ~1–3 минуты, рендер видео ~2–10 минут.
Скрипт ждёт сам и скачивает результат.

## Веб-интерфейс

Если удобнее кликать, а не писать команды:

```bash
python run_webui.py
```

## Частые ошибки

| Сообщение | Что делать |
|---|---|
| `Не найден HEYGEN_API_KEY` | создать `.env` с ключом |
| `Photo avatar not ready` | взять фото чётче, лицо крупнее и анфас |
| `Voice clone failed` | запись длиннее 30 с, без шума и музыки |
| Долго висит | увеличить `--timeout 1800` |

## Длительность

Длительность = длительность речи. Ориентир для русского: ~2,2 слова в секунду.
Для ролика на 15 секунд — примерно 33–35 слов.
