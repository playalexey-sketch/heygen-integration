# Клуб «Царство» — Landing Page

Премиальный лендинг клуба гармоничного роста для женщин.

## Структура

```
tsarstvo/
├── index.html          # Главная страница
├── products.html       # Страница продуктов и тарифов
├── css/styles.css      # Дизайн-система
├── js/main.js          # Анимации, форма, оплата → Telegram
└── assets/             # Визуалы
```

## Telegram-бот

Все кнопки «Оплатить» и форма заявки ведут в бота:

```
https://t.me/tsarstvo_club_bot
```

Параметры `?start=pay_...` передают выбранный продукт.  
Замените username бота в `js/main.js` (константа `TELEGRAM_BOT`) и во всех HTML-ссылках.

## Запуск

```bash
cd tsarstvo
python3 -m http.server 8080
# открыть http://localhost:8080
```
