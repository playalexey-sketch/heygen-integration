# Как запустить HeyGen Студию у себя на компьютере

Инструкция с нуля. Никакого опыта в программировании не нужно.
Всего 4 шага, примерно 10 минут.

---

## Что вы получите

Программу, которая открывается в обычном браузере (как сайт), но работает
на вашем компьютере. В неё вы загружаете фото и голос, описываете словами
желаемый ролик — и получаете готовое видео говорящего цифрового аватара.

---

# ШАГ 1. Установить Python

Python — это движок, на котором работает программа. Ставится один раз.

## Если у вас Windows

1. Откройте https://www.python.org/downloads/
2. Нажмите большую жёлтую кнопку **«Download Python»**
3. Запустите скачанный файл
4. **САМОЕ ВАЖНОЕ:** внизу первого окна установщика поставьте галочку
   **«Add python.exe to PATH»**

   > Без этой галочки программа не запустится. Если забыли — удалите Python
   > через «Установка и удаление программ» и поставьте заново с галочкой.

5. Нажмите **«Install Now»** и дождитесь надписи «Setup was successful»

## Если у вас Mac

1. Откройте https://www.python.org/downloads/
2. Нажмите **«Download Python»**
3. Откройте скачанный файл `.pkg` и нажимайте «Продолжить» до конца

## Проверка, что установилось

**Windows:** нажмите `Win + R`, впишите `cmd`, нажмите Enter.
**Mac:** нажмите `Cmd + Пробел`, впишите `Терминал`, нажмите Enter.

В открывшемся чёрном (или белом) окне напечатайте команду и нажмите Enter:

```
python --version
```

Должна появиться надпись вроде `Python 3.12.1`.

> Если пишет «команда не найдена» — на Mac попробуйте `python3 --version`.
> Если и так не работает на Windows — Python установлен без галочки PATH,
> переустановите (см. пункт 4 выше).

---

# ШАГ 2. Распаковать архив

1. Скачайте файл `heygen_studio.zip`
2. **Обязательно распакуйте его** — не открывайте прямо из архива!

   - **Windows:** правой кнопкой по файлу → **«Извлечь всё»** → «Извлечь»
   - **Mac:** двойной клик по архиву

3. Положите получившуюся папку `heygen_studio` в удобное место,
   например на Рабочий стол

> **Частая ошибка:** запуск программы прямо из окна архива. Windows в этом
> случае распаковывает файлы во временную папку, и ваши видео потом
> невозможно найти. Сначала «Извлечь всё» — потом запускать.

---

# ШАГ 3. Первый запуск — знакомство без затрат

Попробуем программу в **тестовом режиме**: всё работает по-настоящему,
но запросы уходят не в HeyGen, а во встроенный имитатор.
Ключ не нужен, деньги не тратятся.

1. Откройте папку `heygen_studio`
2. Найдите файл:
   - **Windows:** `ТЕСТОВЫЙ_РЕЖИМ.bat`
   - **Mac:** `ТЕСТОВЫЙ_РЕЖИМ.command`
3. Сделайте по нему **двойной клик**

Откроется чёрное окно с текстом — это нормально, **не закрывайте его**,
пока работаете с программой. Через 10–60 секунд браузер откроется сам
на странице программы.

> **Первый запуск дольше обычного:** программа доустанавливает нужные
> компоненты. Дальше будет открываться за пару секунд.

### Если браузер не открылся сам

Откройте браузер и вручную введите в адресную строку:

```
localhost:8300
```

### Возможные предупреждения при первом запуске

| Что видите | Что делать |
|---|---|
| **Windows:** «Система Windows защитила ваш компьютер» | Нажмите «Подробнее» → «Выполнить в любом случае» |
| **Windows:** запрос брандмауэра о доступе к сети | Нажмите «Разрешить доступ» |
| **Mac:** «Не удаётся открыть, так как разработчик не подтверждён» | Правой кнопкой по файлу → «Открыть» → в окне снова «Открыть» |

### Попробуйте прямо сейчас

В самом верху страницы есть поле **«Опишите свободно, что хотите получить»**.
Впишите туда, например:

> Хочу вертикальный ролик для Reels секунд на 20, настроение спокойное
> и доверительное, субтитры в кадре, тёмный фон.
> Текст: «Проверяю, как работает программа.»

Нажмите **«Разобрать описание»** — увидите, как агент сам подобрал все
настройки и объяснил каждое решение. Дальше «Утвердить и применить»,
выбрать фото и голос, «Создать видео».

Чтобы **закрыть программу** — просто закройте чёрное окно.

# ШАГ 4. Боевой режим — с настоящим HeyGen

Когда освоились, подключаем настоящий сервис.

## 4.1. Получить ключ

1. Зарегистрируйтесь на https://www.heygen.com
2. Зайдите на страницу https://app.heygen.com/settings/api
3. Нажмите кнопку создания ключа (**Create API Key** / **Show**)
4. Скопируйте длинную строку символов — это и есть ваш ключ

> Ключ — как пароль от вашего кошелька в HeyGen. Никому не показывайте
> и не выкладывайте в интернет. Программа хранит его только у вас
> на компьютере, в файле `settings.json`.

## 4.2. Запустить обычный режим

Двойной клик по:
- **Windows:** `ЗАПУСТИТЬ.bat`
- **Mac:** `ЗАПУСТИТЬ.command`

## 4.3. Вставить ключ

1. В программе раскройте самый верхний блок **«Настройки подключения»**
2. Вставьте ключ в поле **«Ключ API HeyGen»**
3. Нажмите **«Сохранить»**
4. Нажмите **«Проверить связь»**

Должна появиться зелёная надпись вида
*«Связь есть. Голосов: 300, аватаров: 5»*. Готово, можно работать.

Ключ вводится **один раз** — программа его запомнит.

# Как сделать первое настоящее видео

1. **Блок «Как будем настраивать»** — опишите словами, какой хотите ролик,
   нажмите «Разобрать описание», проверьте подобранное, нажмите
   **«Утвердить и применить»**

2. **Блок 1 «Внешность аватара»** — загрузите своё фото
   *(агент это не подбирает — только вы)*

   Требования к фото: анфас, лицо крупно, глаза открыты, ровный свет,
   без очков и головных уборов, шириной от 1000 пикселей

3. **Блок 2 «Голос»** — выберите один из вариантов
   *(агент это не подбирает — только вы)*

   - **«Из библиотеки»** — нажмите «Загрузить голоса», в фильтр впишите
     `Russian`, выберите голос и послушайте
   - **«Клонировать мой»** — загрузите запись своего голоса
     на 30–120 секунд, чистую, без музыки и шума

4. Нажмите **«Создать видео»** внизу

5. Ждите 2–10 минут. Появится плеер и кнопка **«Скачать видео»**

> Если клонировали голос — программа покажет его **ID**. Нажмите
> «Сохранить этот голос для будущих роликов», чтобы в следующий раз
> не клонировать заново (это экономит время и деньги).

# Если что-то пошло не так

| Проблема | Решение |
|---|---|
| Окно мигнуло и сразу закрылось | Python не установлен или установлен без галочки PATH. Вернитесь к Шагу 1 |
| «python не является внутренней или внешней командой» | То же самое — переустановите Python с галочкой «Add python.exe to PATH» |
| Браузер не открылся | Введите вручную `localhost:8300` в адресной строке |
| Страница не грузится | Посмотрите в чёрное окно: там написана строка «Откройте в браузере: …». Если порт 8300 был занят, программа сама возьмёт 8301 и напишет об этом |
| «Ключ API отклонён» | Ключ скопирован не целиком или с лишними пробелами. Скопируйте заново со страницы HeyGen |
| «Недостаточно кредитов» | Закончился баланс — пополните в личном кабинете HeyGen |
| Аватар не создаётся из фото | Фото не подходит: нужен портрет анфас, лицо крупно, ровный свет, без очков |
| «Клонирование не удалось» | Запись слишком короткая или шумная. Нужно 30–120 секунд чистой речи одного человека |
| Не могу найти готовое видео | Папка `videos` внутри `heygen_studio`. Также весь архив роликов есть внизу страницы программы |
| Всё сломалось непонятно почему | Удалите файл `settings.json` и запустите заново. Ключ придётся ввести повторно |

## Проверить, что программа исправна

Откройте чёрное окно (терминал) в папке `heygen_studio` и выполните:

```
python test_all.py
```

Программа сама себя проверит по 105 пунктам и напишет
`ПРОЙДЕНО: 105 из 105`. Кредиты при этом не расходуются.

# Полезно знать

**Программа работает только пока открыто чёрное окно.** Закрыли окно —
программа остановилась. Это нормально.

**Интернет нужен** — видео создаётся на серверах HeyGen, а не на вашем
компьютере. Ваш компьютер только отправляет задание и скачивает результат.

**Где лежат файлы** — всё внутри папки `heygen_studio`:

| Папка / файл | Что внутри |
|---|---|
| `videos` | готовые видео и субтитры |
| `work` | загруженные вами фото и аудио |
| `settings.json` | ваш ключ и сохранённые голоса |

**Как обновить программу** — распакуйте новый архив поверх старой папки,
согласившись на замену файлов. Папки `videos` и `settings.json`
из старой версии можно сохранить.

**Про адрес `localhost:8300`** — если этот порт занят другой программой,
Студия сама возьмёт следующий свободный (8301, 8302…) и напишет об этом
в чёрном окне. Всегда сверяйтесь со строкой «Откройте в браузере».

**Задать порт вручную** — откройте терминал в папке программы:

```
python start.py --port 8400
```
