# HeyGen Студия — как запустить

Приложение для создания видео цифрового аватара: все настройки HeyGen
в одной форме на русском языке.

---

## Шаг 1. Установить Python (если ещё нет)

Нужен **Python 3.9 или новее**: https://www.python.org/downloads/

> **Windows:** при установке обязательно отметьте галочку
> **«Add Python to PATH»** на первом экране установщика.

Проверка — откройте терминал (Windows: «Командная строка», Mac: «Терминал»):
```
python --version
```

## Шаг 2. Распаковать архив

Распакуйте `heygen_studio.zip` в любую папку, например на Рабочий стол.

## Шаг 3. Запустить

**Windows** — двойной клик по файлу `ЗАПУСТИТЬ.bat`

**Mac / Linux** — двойной клик по `ЗАПУСТИТЬ.command`
(либо в терминале: `python3 start.py`)

При первом запуске программа сама доустановит нужные библиотеки — это займёт
минуту. Затем браузер откроется автоматически на `http://localhost:8300`.

## Шаг 4. Указать ключ

1. В приложении раскройте блок **«Настройки подключения»**
2. Вставьте ключ API из личного кабинета HeyGen:
   https://app.heygen.com/settings/api
3. Нажмите **«Сохранить»**, затем **«Проверить связь»**

Ключ хранится только на вашем компьютере, в файле `settings.json`.

---

## Тестовый режим — попробовать без ключа и без списания кредитов

**Windows:** двойной клик по `ТЕСТОВЫЙ_РЕЖИМ.bat`
**Mac / Linux:** `python3 start.py --test`

Запустится встроенный эмулятор HeyGen. Форма работает полностью: все поля,
загрузка файлов, прогресс, скачивание готового файла — но запросы уходят
не в HeyGen, а в локальный эмулятор. Кредиты не расходуются.

## Два способа настроить ролик

### 1. Описать словами (режим по умолчанию)

В блоке **«Как будем настраивать»** напишите обычным текстом, что хотите:

> Хочу вертикальный ролик для Reels секунд на 20. Настроение спокойное,
> доверительное, тон эксперта. Нужны субтитры прямо в кадре, тёмный фон.
> Текст: «Ты замечал, что в твоём Роду всё повторяется по кругу?»

Нажмите **«Разобрать описание»**. Агент подберёт формат, качество, движок,
выразительность мимики, поведение в кадре, фон, субтитры, скорость и эмоцию
речи, язык, а также вытащит текст речи из кавычек.

Появится карточка со **всеми подобранными параметрами и объяснением каждого
решения**. Проверяете → **«Утвердить и применить»** → значения проставляются
в форму, все блоки настроек раскрываются (можно доправить руками) →
выбираете фото и голос → **«Создать видео»**.

> **Голос и фото агент не подбирает** — это ваш выбор, блоки 1 и 2.

Если что-то не устроило: **«Разобрать заново»** после правки описания
или **«Открыть все настройки»** для ручного режима.

### 2. Настроить всё вручную

Вкладка **«Настрою всё сам»** — открываются все блоки, как обычно.

Режимы совместимы: можно начать с описания, утвердить, а потом
доправить любое поле руками.

## Что есть в форме

| Блок | Настройки |
|---|---|
| **Свободное описание** | пишете задачу словами — агент подбирает все параметры, кроме голоса и фото, показывает их с объяснением и ждёт вашего утверждения |
| **1. Внешность аватара** | из своих фото (можно несколько) · готовый аватар из аккаунта · создание персонажа по текстовому описанию с выбором возраста, пола, этнотипа, стиля, ориентации кадра и крупности плана |
| **2. Голос** | из библиотеки HeyGen с прослушиванием · клонирование своего голоса · ранее клонированный по ID · свой аудиофайл · аудио по ссылке. Плюс тонкая настройка: скорость, высота, громкость, эмоция подачи, язык и акцент, схожесть с оригиналом, стабильность, усиление чёткости |
| **3. Текст речи** | до 5000 символов, со счётчиком слов и оценкой длительности |
| **4. Поведение в кадре** | сценарий движений и жестов · движок генерации (Avatar IV / V / III) · выразительность мимики |
| **5. Формат видео** | соотношение сторон (9:16, 16:9, 4:5, 1:1, 5:4, авто) · разрешение (720p, 1080p, 4K) · формат файла (MP4 / WebM с прозрачным фоном) · название ролика |
| **6. Фон** | оставить · удалить (прозрачный) · сплошной цвет · картинка по ссылке · свой файл |
| **7. Субтитры** | отдельный файл SRT или VTT · вшивание текста в кадр |
| **8. Дополнительно** | водяной знак (ссылка, положение, размер, прозрачность, отступы) · адрес уведомления о готовности · словарь произношения |

Результат: плеер прямо в браузере, кнопка скачивания видео и субтитров,
архив всех созданных роликов внизу страницы.

## Частые вопросы

**Порт занят**
```
python start.py --port 8400
```

**Ошибка «Ключ API отклонён»** — проверьте ключ в блоке настроек;
он должен быть скопирован целиком, без пробелов.

**Ошибка «Недостаточно кредитов»** — пополните баланс в кабинете HeyGen.

**Аватар не создаётся из фото** — нужен портрет анфас, лицо крупно,
ровный свет, без очков и головных уборов, от 1000 пикселей по ширине.

**Клонирование голоса не удалось** — нужна чистая запись 30–120 секунд,
один говорящий, без музыки и посторонних шумов.

**Сколько ждать** — клонирование голоса 1–3 минуты, рендер видео 2–10 минут.
Вкладку закрывать не нужно, прогресс обновляется сам.

## Где что лежит

| Папка / файл | Содержимое |
|---|---|
| `videos/` | готовые видео и субтитры |
| `work/` | загруженные вами материалы |
| `settings.json` | ваш ключ и сохранённые голоса |
| `test_all.py` | автотест всего механизма (105 проверок) |

## Проверить, что всё исправно

```
python test_all.py
```
Прогоняет 105 проверок на встроенном эмуляторе, не тратя кредиты.
