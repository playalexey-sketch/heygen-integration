# Детальный анализ пути: Бренд с нуля → Лиды → Продажи на автомате для экспертов и бизнеса

> Этот документ — анализ типичного пути (который был в референсе autoexpert.html, но файл не открылся в среде) + улучшенная версия через фабрику агентов. Если пришлешь содержимое референса — дополню.

## 0. Диагностика исходного пути (как обычно делают)

Типичный путь у 90% экспертов:
1. Идея → веду блог как все
2. Упаковка профиля на вкус
3. Посты без системы
4. Иногда Reels
5. В шапке ссылка на ТГ
6. Лиды в директ руками
7. Продажи через "напиши в директ"
8. Выгорание

### Боли этого пути:
- Нет данных о рынке → ниша выбрана наугад
- Нет распаковки → контент обезличен
- Нет ICP → "для всех"
- Нет позиционирования → не запоминается
- Нет доказательств → не верят
- Нет лестницы → теряется LTV
- Нет контент-системы → выгорание, 1 Reels в 3 дня
- Нет автоворонок → все руками
- Нет CRM → лиды теряются
- Нет скриптов → сливают продажи

### Потери:
- 3 месяца на "попробую"
- 32 часа в месяц на контент который не продает
- 70-80% лидов теряется в директе
- Нет актива (базы, автоворонок)

## 1. Улучшенный путь — 7 фаз, 21 агент, 25 артефактов

### Принцип улучшений:
1. **Manifest-driven**: единый машиночитаемый бриф `brand_brief.json` + человекочитаемый `brand_manifest.md` → вход для всех агентов
2. **Agent Factory**: каждый шаг делает агент с унифицированным интерфейсом (входы → выходы → Approve)
3. **Human-in-the-loop**: человек видит промежуточные md, картинки, видео, утверждает
4. **Asset passing**: md, json, image, video, manifest передаются по цепочке без потерь
5. **HeyGen интеграция**: фото эксперта → говорящее видео без съемок, используется в Phase 6
6. **Быстро, удобно, комфортно**: одна веб-фабрика вместо 5 сервисов (Notion + GDocs + Figma + Miro + Sheets)

### PHASE 1: FOUNDATION & BRAND DNA (за 1 день вместо 3 мес)
**Цель:** За 1 день собрать фундамент, который обычно собирают месяцами.

#### Подфазы и задачи:

**1.1 Валидация ниши и рынка** — агент `market_researcher`
- Проблемы ДО: выбирают нишу наугад, нет данных о спросе
- Улучшено: агент сканирует тренды, поисковые запросы, топ конкурентов, находит gaps
- Задачи:
  - Сбор 20 поисковых интентов (Wordstat, YouTube поиск, комменты)
  - Топ-10 конкурентов: что продают, цены, слабые места
  - Тренд-анализ: что растет в ближайшие 6 мес (AI аватары, DM триггеры, трипваеры 990р)
  - Карта болей → желаний (20/20)
- Артефакты: `01_market_report.md`, `01_keywords.md`, `01_trends.json`
- Human checkpoint: утвердить нишу и угол входа

**1.2 Распаковка эксперта** — `expert_auditor`
- Проблемы ДО: эксперт не может сформулировать суперсилу, контент без личности
- Улучшено: AI-интервью 30 вопросов + сразу генерятся story-bank для Reels
- Задачи:
  - Superpower интервью 30 вопросов
  - Оцифровка кейсов (до/после цифры)
  - Банк историй 7 типов: провал, прорыв, клиент, закулисье, миссия, разоблачение, инструмент (HeyGen демо)
  - Название методологии в 3-5 шагов
- Артефакты: `02_expert_dossier.md`, `02_superpowers.md`, `02_stories_bank.md`
- Checkpoint: проверить истории и суперсилу

**1.3 ICP и JTBD** — `icp_architect`
- Проблемы ДО: "для всех", нет языка клиента
- Улучшено: 3 аватара с фото-описанием, цитатами, триггерами покупки, возражениями
- Задачи:
  - Сегментация 3 уровня: новичок, продвинутый, бизнес
  - JTBD: Когда [ситуация], хочу [результат], чтобы [мотив], но мешает [барьер]
  - Топ-10 возражений + ответы
  - Триггеры покупки (что заставит купить сейчас)
- Артефакты: `03_icp_avatars.md`, `03_icp_map.json`, `03_objections.md`

**1.4 Позиционирование и Big Idea** — `positioning_strategist`
- Проблемы ДО: "я эксперт по всему", не запоминается
- Улучшено: формула + Big Idea + Enemy + One-liners для шапок (5 вариантов)
- Задачи:
  - Формула: Я помогаю [кому] получить [что] через [как] за [срок] без [боль]
  - Big Idea и Враг (против чего боремся)
  - 3 One-liner для био
  - Тест уникальности vs 5 конкурентов
- Артефакты: `04_positioning.md`, `04_big_idea.md`, `04_one_liners.md`

**1.5 Доказательства и Authority** — `proof_collector`
- Проблемы ДО: нет кейсов, нет доверия
- Улучшено: автопакует кейсы по CASE: Context-Action-Specific-Effect + Authority Stack
- Задачи:
  - 3 кейса минимум по шаблону
  - Цифры: сколько клиентов, средний результат
  - Социальное доказательство: как собирать отзывы автоматом (бот через 14 дней)
- Артефакты: `05_proof_board.md`, `05_case_templates.md`, `05_authority_stack.md`
- Нужно от человека: загрузить скрины/фото доказательств (передаются как артефакты image)

**1.6 Конкуренты и возможности** — `competitor_analyst`
- Проблемы ДО: копируют конкурентов, не видят возможностей
- Улучшено: Gap-матрица + 5 идей как отстроиться
- Задачи: разбор аккаунтов, продуктов, гэпов, Ideas Bank
- Артефакты: `06_competitor_map.md`, `06_gap_opportunities.md`

**1.7 Brand Manifest и Brief** — `manifesto_synthesizer`
- Проблемы ДО: хаос, нет единого видения
- Улучшено: один манифест = бриф для всех следующих агентов и дизайнеров + json для машин
- Задачи: свести манифест (миссия, ценности, тон, ICP, позиционирование, proof, визуал-наметки, roadmap), создать brand_brief.json, Approve человеком
- Артефакты: `07_brand_manifest.md` (главный документ фазы 1, 2-3 страницы), `07_brand_brief.json` (машиночитаемый), `07_next_steps.md`

**Итог Phase1:** Brand Manifest + Brief утвержден человеком → вход для Phase2-7.

## 2. Сеть агентов — фабрика (как реализовано в коде)

### Унифицированный интерфейс агента (BaseAgent)
Каждый агент наследует `agents/base.py`:

```python
id, manifest(name, icon, role, description)
inputs_required: List[str]  # что нужно: niche, expert_dossier.md, icp.md, фото и тд
outputs_produced: List[str] # что генерит: 01_market_report.md etc
dependencies: List[str]     # кто должен быть approved до него
tasks: List[str]
human_checkpoints: List[str]
status: idle|waiting_input|ready|running|needs_review|approved|failed
progress, message, error, outputs[], review_notes
run(project, context) -> List[Artifact]
```

### Передача данных
- Artifact: id, filename, type(md/json/image/video/manifest), path, created_by, description, size, preview_url
- Все в `/brand_factory/projects/{proj_id}/artifacts/`
- Агент читает через `get_artifact_content(pid, filename)` → генерит новое → `add_artifact(...)`
- Человек в UI видит: входы, выходы, превью md, логи, кнопки Run/Approve/Reject/Regenerate
- Approval разблокирует зависимые агенты (проверка всех dependencies approved)

### Поток Phase1 (пример):
```
User Input (ниша, эксперт, истории, proof, конкуренты)
 → market_researcher → 01_*.md
 → expert_auditor + competitor_analyst → 02_*.md + 06_*.md
 → icp_architect → 03_*.md
 → positioning_strategist + proof_collector → 04_*.md + 05_*.md
 → manifesto_synthesizer → 07_brand_manifest.md + 07_brand_brief.json
 → HUMAN APPROVE → Phase2
```

### Веб-приложение (единое)
- FastAPI `brand_factory/server.py` порт 8002
- UI `ui/index.html + app.js`: Tailwind, glass, dark
- Вкладки: Phase1..Phase7, Overview, Factory Graph, Artifacts, Journey Map
- Левая панель: проекты + прогресс фабрики
- Phase1 мастер: форма входных данных + загрузка файлов (фото, скрины кейсов) + pipeline агентов + превью манифеста
- Artifacts галерея

## 3. Пример первой фазы (фактический результат из демо-проекта)

Проект `proj_ebde53d7` — ниша "эксперты по продуктивности", эксперт Мария, 5 лет опыта.

Сгенерировано 20 артефактов за 7 прогонов агентов:

- `01_market_report.md` — объем, топ-5 конкурентов, 20 запросов, боли/желания, gaps
- `02_expert_dossier.md` — распаковка, метод AUTO-EXPERT 3 опоры, 30 вопросов
- `02_stories_bank.md` — 7 типов историй для Reels
- `03_icp_avatars.md` — 3 аватара, JTBD, возражения, триггеры
- `04_positioning.md` — формула позиционирования, Big Idea, one-liners
- `05_proof_board.md` — CASE формула, что собрать
- `06_competitor_map.md` — таблица сравнения, gaps

- `07_brand_brief.json` — машиночитаемый бриф для следующих фаз

Время: ~35 сек на всех 7 агентов (мок-генерация). С LLM было бы 3-5 мин, но структура та же.

## 4. Что можно улучшить еще (roadmap)

1. Подключить LLM (OpenAI/Anthropic) в `run()` — сейчас шаблоны, интерфейс готов
2. Подключить генерацию каруселей как картинки через `generate_image`
3. Реальная интеграция HeyGen: в `heygen_video_factory` вызывать `heygen_client.create_avatar_video` с фото эксперта

5. Instagram Graph API для автопостинга из editorial plan
6. Мульти-агент дебаты: 2 агента предлагают позиционирование, человек выбирает
7. Voice cloning для HeyGen из загруженного аудио

## 5. Как запустить

```bash
pip install --break-system-packages fastapi uvicorn pydantic python-multipart
PORT=8002 python -m brand_factory.server
# http://localhost:8002
```

Создать проект → заполнить Phase1 входы → запустить агентов по очереди → Approve → смотреть Artifacts и Factory Graph.

Все файлы проекта лежат в `brand_factory/projects/{id}/`
