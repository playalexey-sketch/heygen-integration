Настройки

        

          
Файлы .env

          
Агент читает настройки из этих файлов (переменные окружения имеют приоритет):

          
    
          
    Создайте .env из шаблона: copy timeweb_agent\.env.example .env (Windows) или cp timeweb_agent/.env.example .env (Linux/macOS).
    
        
    
        
    
          
    Текущие настройки
    
          
    
          
    Пароли и токены показываются маскированными. Чтобы что-то изменить — отредактируйте .env и перезапустите панель.
    
        
    
        
    
          
    Где взять токен
    
          
    Панель Timeweb → раздел «API и Terraform» → «Создать токен»:
          timeweb.cloud/my/api-keys.
          Вставьте его в .env как TIMEWEB_CLOUD_TOKEN=ваш_токен.
