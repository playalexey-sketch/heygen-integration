# Локальный Qwen + Bionic + фабрика агентов

Коротко: **скачанный GGUF поднимаете в LM Studio / Bionic**, там же болтаете как с человеком.  
**Несколько агентов, которые сами переписываются, Bionic не умеет** — для этого в этом репозитории есть пульт `factory/`. Вы только смотрите и жмёте «Далее».

## Честная схема

| Что хотите | Чем пользоваться | 1.5B потянет? |
|---|---|---|
| Человеческий чат | Bionic → Work project, или вкладка «Чат» в пульте | да, на короткие реплики |
| Один агент, который трогает файлы/код | Bionic → Code / Work | слабо. Для агента нужен ≥7B |
| Несколько ролей, спор, конвейер, вы за пультом | этот пульт (`run_factory.py`) | демо / игрушка. Для пользы ≥7B |

Bionic — **один** агент в одном окне. У него нет «фабрики», где Исследователь спорит с Критиком, а вы только утверждаете ход.

## 1. Поднять скачанный `Qwen2.5-1.5B-Instruct-GGUF`

### Вариант A — через LM Studio / Bionic (то, что у вас уже стоит)

1. Найдите файл `*.gguf` (часто это `*Q4_K_M.gguf`).
2. В терминале:

```bat
lms import "C:\Users\ВАШ_ЛОГИН\Downloads\qwen2.5-1.5b-instruct-q4_k_m.gguf" --copy --user-repo Qwen/Qwen2.5-1.5B-Instruct -y
```

Если команды `lms` нет:

- откройте **LM Studio → Settings → Enable CLI**, перезапустите терминал;
- или скопируйте файл вручную в папку с **двумя** уровнями:

```
%USERPROFILE%\.lmstudio\models\Qwen\Qwen2.5-1.5B-Instruct\qwen2.5-1.5b-instruct-q4_k_m.gguf
```

На Linux/macOS это `~/.lmstudio/models/Qwen/Qwen2.5-1.5B-Instruct/`.

3. Откройте **Bionic** → библиотека моделей → выберите `Qwen2.5-1.5B-Instruct` → Load.  
   1.5B спокойно едет на CPU, видеокарта не обязательна.

4. Создайте **Work project** — это и есть человеческий чат.

### Вариант B — без Bionic, просто llama.cpp

```bat
llama-server -m "C:\путь\к\модели.gguf" --host 127.0.0.1 --port 8080 -c 4096
```

Появится OpenAI-совместимый сервер `http://127.0.0.1:8080/v1`.

### Вариант C — Ollama из вашего GGUF

`Modelfile`:

```
FROM C:\путь\к\qwen2.5-1.5b-instruct-q4_k_m.gguf
```

```bat
ollama create qwen2.5-1.5b -f Modelfile
ollama run qwen2.5-1.5b
```

## 2. Отдать ту же модель фабрике агентов

Bionic и классический LM Studio делят библиотеку моделей. Фабрике нужен **HTTP-сервер**:

```bat
lms load Qwen2.5-1.5B-Instruct --gpu=off
lms server start --port 1234
```

Либо в LM Studio: вкладка **Developer → Start Server**.

Проверка:

```bat
curl http://127.0.0.1:1234/v1/models
```

Дальше в папке проекта:

```bat
pip install -r requirements.txt
python run_factory.py
```

Открыть [http://localhost:8003](http://localhost:8003).

В **Настройках модели** нажмите «Найти сервер». Должен загореться LM Studio.  
Если сервера нет — пульт сам включит **демо-режим**, чтобы вы увидели, как агенты ходят по кругу.

## 3. Как пользоваться пультом (вы только следите)

1. **Агенты** — уже есть Исследователь, Критик, Писатель, Планировщик, Инженер, Скептик, Ведущий. Можно добавить своего: имя + 2–4 предложения «кто ты».
2. **Фабрики** — цель + 2–4 агента + режим:
   - **по кругу** — говорят по очереди;
   - **конвейер** — выход одного становится входом следующего;
   - **спор** — сталкивают позиции, Ведущий сводит.
3. **Запустить** → вы на **Пульте**:
   - **Далее** — разрешить следующий ход (так и задумано на 1.5B);
   - **Вмешаться** — ваша реплика попадает в стенограмму, все её видят;
   - **Пауза / Стоп / Итог**.

По умолчанию фабрика **не бежит сама**. Это и есть «я только слежу».

---

## 4. Почему 1.5B — потолок игрушки

`Qwen2.5-1.5B-Instruct` хорошо отвечает коротко. Он плохо:

- держит роль дольше 3–4 ходов;
- вызывает инструменты (то, чем живёт Bionic Code);
- ведёт «завод» из 6 агентов без повторов и галлюцинаций.

Практичный апгрейд, тот же GGUF-путь:

| ОЗУ | Модель | Зачем |
|---|---|---|
| 8 ГБ | Qwen2.5-1.5B Q4 (то, что есть) | чат, демо-фабрика |
| 16 ГБ | **Qwen2.5-7B-Instruct Q4_K_M** | уже похоже на команду |
| 32 ГБ | Qwen2.5-14B / Qwen3-8B–14B | нормальные агенты |

Импорт ровно тот же: `lms import файл.gguf --copy`.

---

## 5. Если что-то не находится

- Bionic не видит GGUF → файл лежит не в `publisher/model/*.gguf`, а россыпью в Downloads.
- `lms` не находится → CLI не включён в LM Studio.
- Пульт пишет «демо» → сервер на :1234 не запущен или модель не loaded. `lms ps` покажет, что в памяти.
- Два приложения сразу жрут память → либо Bionic, либо `lms server`, не оба на большой модели. 1.5B проживёт и так.
