# Аватар-Студия

Интерактивная форма: фото + голос + сценарий → готовое видео цифрового аватара со ссылкой на скачивание.

## Запуск

```bash
pip install -r requirements.txt
python -m studio.server
```

Открыть http://localhost:8010
Порт меняется переменной `STUDIO_PORT`.

## Ключ

В корне проекта файл `.env`:
```
HEYGEN_API_KEY=hg_твой_ключ
```
Без ключа форма откроется, но покажет предупреждение — генерация не запустится.
Ключ: https://app.heygen.com/settings/api

## Блоки формы

**1. Внешность аватара**
- *Мои фото* — загрузка нескольких фото (drag & drop). Первое помечается `ОСНОВНОЕ`
  и идёт в работу, остальные хранятся как запасные ракурсы для повторной попытки.
- *Готовый аватар* — кнопка подгружает цифровых аватаров твоего аккаунта с превью.

**2. Голос** — три режима:
| Режим | Что делает | Нужен текст? |
|---|---|---|
| 🎧 Моя озвучка | аватар липсинкает загруженный аудиофайл | нет |
| 🎙 Клонировать мой голос | клонирует голос из образца 30–120 с | да |
| 🔊 Голос из библиотеки | голос HeyGen с прослушиванием превью | да |

**3. Текст речи** — со счётчиком слов и оценкой длительности (~2,2 слова/сек).

**4. Детальный сценарий** — эмоция, жесты, план, атмосфера. Уходит как motion prompt.

**5. Формат** — соотношение сторон (9:16 / 16:9 / 1:1), качество, фон, название.

## Результат

Прогресс-бар с этапами и живым логом. По готовности — плеер прямо в браузере
и кнопка **Скачать видео**. Файлы складываются в `studio_output/`.

При клонировании студия покажет **ID твоего голоса** — сохрани его,
чтобы следующие ролики делать без повторного клонирования.

## Требования к материалам

**Фото:** анфас, лицо крупно, глаза открыты, ровный свет, без очков и кепки,
подбородок не обрезан, от 1000 px.

**Голос:** 30–120 секунд чистой речи, один говорящий, без музыки и шума, MP3/WAV.

## Сколько ждать

Клонирование голоса 1–3 минуты, рендер 2–10 минут. Вкладку можно не закрывать —
прогресс обновляется автоматически.
